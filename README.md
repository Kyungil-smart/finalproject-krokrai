# 냥스타3
## 목차
- 팀 및 프로젝트 소개
- 게임 소개
- 게임 주요 기능

## 팀 및 프로젝트 소개
- 게임 실행 환경 : 안드로이드 모바일 전용
- 제작 엔진 : Unity 2022.3
- 제작 기간 : 26.05.20 ~ 26.07.16
- 제작 인원 : 기획 9 / 플밍 5

## 게임 소개
- 모바일 힐링 게임 냥냥스타의 기업 협약용 프로젝트로 게임에 컨셉을 기반으로 추가 컨텐츠 제작한 방식입니다.
- 실제 게임과 다른 환경이므로 원본 게임과 다름을 인지하고 플레이해주세요.
- 기본 조작 방식 : 터치

## 게임 주요 기능
- 캡처 : 메인 게임 화면에서 특정 가구(의자, 침대, 소파)를 홀딩시 메뉴가 뜨며, 카메라 모양 클릭 시 전용 이미지 획득

- SNS
  - 홈피드 : DM에서 선택한 방식에 따라 홈피드가 추가되며, 우측 상단에서 DM 진입 가능합니다.
  - DM : 진행 상황에 따라 DM을 보내는 NPC가 추가되고 진행하면 보상을 받습니다
  - 업로드 : 기본 지급 5장 및 캡처를 통해 획득한 이미지를 냥스톤 1개를 소모해 업로드 가능합니다.
  - 미니게임 : 구현된 게임은 1개이며, 짝 맞추기를 통해 미니게임 토큰을 얻을 수 있으며, 전용 상점에서 재화를 얻을 수 있습니다.
  - 프로필 : 업로드된 이미지들 및 해당 이미지를 클릭시 게시물 형태로 넘어가며, 현재 팔로워 수 및 우측 상단에서 DM 진입 가능

- 시뮬레이터 : 기존 게임에서 획득해야 되는 재화를 얻을 수 있게 만든 시뮬레이터입니다.

- 방치형 : 팔로워 수에 비례해서 보상을 얻을 수 있습니다.

- 냥냥베이커리 : 접속 시간에 비례해 보상을 얻고 전용 상점에서 재화 구매 가능합니다.
